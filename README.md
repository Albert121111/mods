# Потрать деньги Илона Маска

Оригинальная браузерная игра о том, как потратить условное состояние Илона Маска в размере **62 448 565 000 000 ₽**.

Все исходные цены переведены в рубли по курсу **$1 = 73,4689 ₽**. Суммы и количества отображаются полностью с разделителями разрядов.

## Онлайн-версия

Игра опубликована на GitHub Pages:  
https://albert121111.github.io/mods/

## Запуск

Зависимости и сборка не нужны.

1. Откройте файл `index.html` в современном браузере.
2. Или запустите локальный сервер из папки проекта:

```powershell
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Возможности

- 107 товаров в 7 категориях;
- локальные тематические фотографии из Unsplash;
- покупка, продажа и покупка максимального количества;
- поиск, фильтры и четыре варианта сортировки;
- статистика, прогресс состояния и финальный экран;
- сохранение прогресса в `localStorage`;
- светлая и темная темы;
- адаптивная версия для телефона;
- анимации, уведомления и конфетти на отметках 50%, 90% и 99%.

## Структура

- `index.html` — разметка приложения;
- `styles.css` — дизайн, адаптивность и анимации;
- `products.js` — каталог товаров;
- `app.js` — игровая логика и сохранение.

Фанатская браузерная игра. Все цены условные.
